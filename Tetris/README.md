# 🎮 Tetris Klassik O'yini (Desktop)

Desktop uchun maxsus tayyorlangan, professional va zamonaviy neon dizayndagi Tetris o'yini.

---

## 🚀 O'yinni ishga tushirish

O'yinni ishga tushirishning 3 xil oson usuli bor:

1. **Desktopdagi yorliq orqali (Eng osoni)**:
   - Ish stolingizda (Desktop) joylashgan **`Tetris_O'yini.bat`** faylini ikki marta bosing.

2. **Python orqali**:
   - `Tetris` papkasiga kiring va terminalda quyidagini bajaring:
   ```bash
   python main.py
   ```
   yoki papkadagi **`run_game.bat`** faylini bosing.

3. **Brauzer orqali (Hech qanday o'rnatishlarsiz)**:
   - `Tetris` papkasidagi **`index.html`** faylini ikki marta bosing va brauzerda to'g'ridan-to'g'ri o'ynang!

---

## 🕹️ Boshqaruv tugmalari

| Tugma | Vazifasi |
| :--- | :--- |
| **`←` / `A`** | Shaklni chapga surish |
| **`→` / `D`** | Shaklni o'ngga surish |
| **`↑` / `W` / `X`** | Shaklni soat yo'nalishida burish |
| **`Z`** | Shaklni soatga teskari burish |
| **`↓` / `S`** | Shaklni sekin pastga tushirish |
| **`Bo'shliq (Space)`** | Shaklni darhol pastga tashlash (Hard drop) |
| **`C` / `Shift`** | Shaklni zaxiraga olish / almashtirish (Hold) |
| **`P` / `Esc`** | Pauza (O'yinni to'xtatib turish) |
| **`R`** | O'yinni qaytadan boshlash |
| **`M`** | Ovozni yoqish / o'chirish |

---

## ✨ Imkoniyatlar va Xususiyatlar
- 🎨 **Zamonaviy Neon va Glassmorphism UI**: Bevel 3D shakllar, silliq animatsiyalar.
- 👻 **Ghost Piece (Soya ko'rinishi)**: Shakl qayerga tushishini oldindan ko'rsatib turadi.
- 🎒 **7-Bag Randomizer**: Rasmiy Tetris qoidalariga asoslangan adolatli shakllar ketma-ketligi.
- 🔁 **Wall Kicks (SRS)**: Shakllar devor yoki boshqa bloklar yonida siqilib qolmasdan aylanadi.
- 💥 **VFX & Zarrachalar (Particles)**: Qatorlar portlaganda va bloklar tushganda vizual effektlar.
- 🎵 **Chiptune Audio**: Sintizator orqali yaratilgan yoqimli ovoz effektlari.
- 🏆 **Rekord (High Score)**: Eng yuqori ball avtomatik ravishda saqlanadi.
